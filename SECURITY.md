# Security

This is a local Windows prototype. Keep Windows, WebView2 and graphics drivers updated. Only install releases from a source you trust, verify their checksums, and retain native engine binaries with their matching dependencies.

For a vulnerability, use the repository's private vulnerability reporting feature if the maintainer has enabled it. Otherwise request a private contact channel from the maintainer without posting exploit details or personal data publicly. No dedicated security email or response-time commitment is configured yet.

Useful reports include the affected version, minimal reproduction, impact and sanitized logs. Do not attach private voice samples, transcripts, credentials or complete user-data folders. Ordinary generation quality problems belong in bug reports rather than security reports.
