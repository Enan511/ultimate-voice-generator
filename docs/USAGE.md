# Using Ultimate Voice Generator

1. Install using the setup EXE with its matching BIN files beside it. Choose an empty, writable destination. Shortcuts and the optional uninstaller are selected by default.
2. Open the installed app. In Settings, choose your export folder, format and reference audio/transcript. FLAC is the default export format.
3. Enter one prompt per line. Punctuation is kept. Submit to review, edit or remove individual prompts; Revert returns to raw input.
4. Confirm the batch to start the queue. Pending, Processing, Completed, Failed and review results explain each task's state. Verification can retry missing or changed words.
5. Preview completed audio using play/pause and the scrub bar. Playback starts at 1.0x. The speed slider affects playback; **Update File** permanently replaces that output with a pitch-preserving speed adjustment after verification.
6. Use History to find past items. Regenerate lets you edit the prompt and appends a new task. Delete removes the selected record and associated output; keep a separate copy of audio you want to preserve.

Pronunciation rules replace phrases before synthesis. Check the pronunciation preview to see what the engine receives. Tone/emotion comparisons and listening scores help compare takes; they do not guarantee a specific performance. ASR can itself mishear words, so listen to important results.

The app stores settings/history under user-data in its installation folder. Its default recordings folder is also local; a chosen export folder may be elsewhere. Imported references are local app data. Back up wanted recordings before uninstalling. The uninstaller offers removal of generated recordings and preserves unrecognized/modified files; shared WebView2 and unrelated files are not removed. External files and backups may remain intentionally.

Once engines, models and WebView2 are installed, normal generation is local. No ChatGPT session is required.
